# 黄帝内経（素問・霊枢）原文・注・現代語訳

『黄帝内経』の素問と霊枢を，段落ごとの小さな単位に分け，資料間の異同（校異）・校訂，注釈書の注（原文）と組み合わせたもの。人が読むためだけでなく，LLM が読みやすいことを目指して，1単位を1ファイルにし，ファイルの頭に機械で読める情報（YAML）を付けている。

**現在の状況**：素問・霊枢の全篇について，原文（句読点つき）・校異・校訂・注（原文）・日本語訳・英訳がそろっている（2026-10-11）。張志聡集注・霊枢の割注・釈音・音釈などは原文だけで訳していない。姉妹編に[傷寒論](https://github.com/medicalcloud/shokanron)・[金匱要略](https://github.com/medicalcloud/kinkiyoryaku)がある。

  NNN.ja.md        日本語訳（原文の訳・注の訳・解説）
  NNN.en.md        英訳

- 霊枢：00 叙（史崧），01〜81 本文，82 目録，83 四庫全書提要，84 霊枢集注序（張志聡）。
- 単位の番号：篇ごとの段落の番号（001…）。00・82〜84 は p001…。単位は計 3,068（素問 1,893・霊枢 1,175）。
- **単位の切れ目は編者の段落**：底本には篇の中の段落がほとんどない（素問は1篇が切れずに続く）ので，Wikisource「黃帝內經」（白文）の段落の境目を底本の本文に移して単位にした。
- **素問 第71篇の錯簡**：底本（四部叢刊本）では，少陰之政の前後で本文の二つのかたまりが入れ替わっている（頁の錯簡と考えられる）。Wikisource 白文の順に本文と注を並べ替え，校訂として注釈に記した（2026-10-10）。
- **素問 第71篇の切れた注**：表の形の単位（第6・9・12・15・18・21単位）では，底本の入力（Wikisource）で行末の注の続きが次の行頭の別の注に入っていて，続きの断片が王冰注のように見える（28か所）。原文ではこれを一つの注につなぎ，その単位の末尾の「解説」に，つないだ断片を記した。

### 各単位の中身

- **原文**：底本の本文（新字体）。
- **校異・校訂・注釈**：【校異】資料の間の違い。【校訂】本文を改めたところ。【補】【欠字】下に記す補い・欠字。
- **王冰注・新校正（原文）**（素問）：唐の王冰の注と宋の新校正。〔…〕は注が付く直前の本文。
- **割注（原文）**（霊枢）：本文中の校語・字音。
- **張志聡集注（原文）**：清の張志聡『黄帝内経素問集注』『黄帝内経霊枢集注』の注。訳はしない。
- 篇末の釈音（素問・巻末）・音釈（霊枢・史崧）は篇の `index.md` に原文を置く。訳はしない。

## 底本と，本文の補い・訂正

### 素問の底本

- **どのような本か**：『重廣補注黃帝內經素問』二十四巻の四部叢刊本（明の翻北宋本）。唐の王冰の注と，宋の林億らの新校正を含む。
- **どのように入手したか**：Wikisource（中文維基文庫）「重廣補注黃帝內經素問 (四部叢刊本)」の入力（頁はすべて「未校正」）を，2026-10-08 に Wikisource の API で取得して使った。同じ版を入力した Kanripo（漢籍リポジトリ）の電子テキスト（KR3e0001）は，半丁ほどの抜けが約29か所あるので，底本にせず照合の資料にした。

### 素問の底本に足りないところ

- **第72 刺法論・第73 本病論**：四部叢刊本では篇名と「亡」だけなので，Wikisource「黃帝內經」の白文で補った。遺篇の注は，殆知閣『黄帝内经素问遗篇』（撰者不明）から白文と照合して取り出した。
- **巻24の釈音と顧従徳の識語**：Kanripo にだけあるので，それによった。
- **入力で失われた字**：底本の入力（Wikisource・Kanripo とも）で失われた字は，照合した資料で補った。それでも補えない字（本文4か所・注16か所の計22字と，第69篇の釈音の1字）は，ウェブで調べて，識典古籍（shidianguji.com）の『黄帝内經素問補註釋文』（道藏本）の字や，注・釈音の文脈によって補った。
- **字形の組み合わせだけが記された字**：Wikisource の入力で字の画像に字形の組み合わせ（IDS）だけが記されている字（10種，17か所・計21字）も，道藏本の同じ箇所の字で補った（「冥冥」など）。
- 第5篇「𤙲」・第70篇「𢽬」・第71篇「𡹌」の本文は，照合した資料は「掣」「陳」「崩」に作るが，新校正・王冰注から底本の字はそれらでないことがわかるので，道藏本の字を採った。
- 補ったところには，いずれも【補】と記した。

### 素問の訂正（校訂）

本文を改めたのは134か所。改めたところには【校訂】として，元の字句・各資料の字・改めた理由を記し，訳の解説でも触れた。

1. 照合した資料（底本と同じ版の Kanripo を除く4つ）が，その箇所を持つものすべてで一致して底本と違うところ（6か所）。
2. 第71篇の錯簡（1か所）。
3. 判断による校訂（98か所）：照合した資料に『太素』・『甲乙経』・『類経』・張志聡『素問集注』・王冰注・新校正を加えて比べ，字の誤り・脱字・字の転倒と判断した本文を改めた。資料が一致しなくても一番それらしい字を採った。このうち59か所は，底本が「已」「己」の意で「巳」と書く（うち1か所は「己」の意で「已」と書く）字形の近い字の誤りである。王冰注・新校正の原文の字の誤りは改めず，訳の解説で触れた。
4. 遺篇（第72・73篇）の本文（Wikisource の白文）の判断による校訂（29か所）：殆知閣の三本（重广补注黄帝内经素问・黄帝内经素问・黄帝内经素问遗篇）と比べ，字の誤り・脱字と判断した字を改めた。

### 共通（素問・霊枢）

- **校異**：「X は「…**字**…」に作る」「…の間に，X は「**字**」がある」の形。字体だけの違い・句読点・資料の欠落（底本の方が多い字句）・資料自体の変換の誤り（Wikisource 白文の化けた字など）は記していない。
- **字体**：`字体と変換の方針.md` による（新字体を基本とする）。このほか，剌→刺，柰→奈，麤→粗に直し，底本の「冩・寫」は瀉の意味のものを「瀉」，書き写す意味のもの（注の「傳寫誤」など）を「写」にした。「閒」「廼」は底本のまま。Wikisource の入力で字の画像に字形の説明だけが付いている字のうち，字体の違いだけのもの（「昜」の形の違う「揚」，宋の避諱で最後の点を欠く「絃」）は普通の字にした。画像の番号だけの1種（SKchar2，3か所）は文脈（「己丑己未」「丑未之紀」）から「丑」とした。人名の王冰は「冰」とする。
- **張志聡集注**：Wikisource の入力（簡体字）を新字体にした。素問集注は（ ）の中を注とし，霊枢集注は印がないので行ごとに底本の本文との一致の度合いで本文と注を分けた（約2%の行は判定が曖昧）。素問集注の第80篇の注に，入力でも他のウェブの資料（中醫笈成）でも欠けている字が「□」として2か所（計12字）ある。注は，直前に引かれた本文が終わる段落に付けた。集注が引く本文そのものは載せていない。
