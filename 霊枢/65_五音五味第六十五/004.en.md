# 霊枢 五音五味第六十五 §4 (English translation)

## Translation of the text

Right *zhi*, lesser *zhi*, *zhi zhi*, upper *zhi*, half *zhi*. Right *jue*, *dai jue*, upper *jue*, great *jue*, half *jue*. Right *shang*, lesser *shang*, *dai shang*, upper *shang*, left *shang*. Lesser *gong*, upper *gong*, great *gong*, added *gong*, left *gong*. Common *yu*, confined *yu*, upper *yu*, great *yu*, lesser *yu*.

## Notes

The *Leijing* note: these five lines conclude the above and list the names of the five notes; five for each note make the number of the twenty-five persons.
- The base's 左角宮 is emended to 左宮. The *Lingshu jizhu* reads 左宮 (the *Leijing* reads 左角宮 like the base). This unit lists five names for each note; the fifth *gong* corresponds to the 左宮之人 of the previous chapter (ch. 64), so 角 is taken as an interpolation and removed.
