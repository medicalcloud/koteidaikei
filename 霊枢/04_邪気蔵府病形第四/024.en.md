# 霊枢 邪気蔵府病形第四 §24 (English translation)

## Translation of the text

Qibo answered, "When the complexion is green-blue, the pulse is stringlike; when red, the pulse is hooked; when yellow, the pulse is regularly intermittent; when white, the pulse is hairlike; when black, the pulse is stonelike. If one sees the color but does not find the corresponding pulse, and instead finds the pulse that conquers it, there will be death; if one finds the pulse that generates it, the illness will end."
