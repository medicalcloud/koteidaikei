# 霊枢 玉版第六十 §14 歧伯曰腹脹身熱脈大是一逆也腹鳴而満四肢清泄其脈大…

## 原文

歧伯曰：「腹脹，身熱，脈大，是一逆也；腹鳴而満，四肢清，泄，其脈大，是二逆也；衄而不止，脈大，是三逆也；咳且溲血，脱形，其脈小勁，是四逆也；咳，脱形，身熱，脈小以疾，是謂五逆也。如是者，不過十五日而死矣。其腹大脹，四末清，脱形，泄甚，是一逆也；腹脹便血，其脈大，時絶，是二逆也；咳，溲血，形肉脱，脈搏，是三逆也；嘔血，胸満引背，脈小而疾，是四逆也；咳嘔，腹脹且飱泄，其脈絶，是五逆也。如是者，不及一時而死矣。工不察此者而刺之，是謂逆治。」

## 校異・校訂・注釈

【校訂】「形**肉**脱」：底本（四部叢刊本，Kanripo）は「形**内**脱」に作る。Wikisource（黃帝內經）・殆知閣（黄帝内经灵枢）・霊枢集注は「形肉脱」に作る。形の肉が脱けることをいうので，字形の近い「内」は「肉」の誤りと見て改めた。

【校異】「四末清脱形泄」の間に，Wikisource（黃帝內經）は「**形**」がある。

【校異】「是者不**及**一時而」を，Wikisource（黃帝內經）は「是者不**過**一時而」に作る。

【校異】「溲血形**肉**脱脈搏」を，Wikisource（靈樞經・四庫全書本）は「溲血形**内**脱脈搏」に作る。

【校異】「逆也咳**且**溲血脱」を，殆知閣（黄帝内经灵枢）は「逆也咳**而**溲血脱」に作る。

## 張志聡集注（原文）

〔…也如是者不過十五日而死矣〕【集注】此言血気之逆於経脈者。不過半月而死也。夫血気留滞而成癰膿者。積微之所生。其所由来者漸矣。若失其旋転之機。又不待成癰。而有遄死之害。諸病者。謂凡病多生於営衛血気之不調。非独癰膿也。如腹脹身熱脈大者。逆傷於脾也。腹鳴而満。四肢清泄。其脈大者。逆傷於腎也。肝主蔵血。衄而不止。逆傷肝也。肺朝百脈。輸精於皮毛。咳而溲血形脱。其脈小勁。逆傷肺也。夫心主血脈。肺者心之蓋。咳。形脱身熱。脈小以疾。逆傷心也。夫血脈者。五臓之所生也。血気逆。則失其旋転之機。而反傷其臓真矣。経脈応地之経水。水以応月。不過十五日而死者。随月之盈虚而死。不能終周天之数矣。王子方曰。堪輿家鑿井。度月影以取泉。

〔…且飱泄其脈絶是五逆也如是〕【集注】者。不過一時而死矣。工不察此者而刺之。是謂逆治。（飧葉孫）此言気血之逆於気分者。不過一周時而死矣。夫皮膚分肉之気血。従胃腑而注於臓腑之大絡。従大絡而出於孫絡。従孫絡而外滲於皮膚。如腹大脹。四肢清。形脱泄甚。是逆於胃之大絡。不得出於皮膚。充於四体也。腹脹便血。其脈大時絶。逆於腎絡也。咳溲血。形肉脱。脈搏逆於肺絡也。嘔血胸満引背。脈小而疾。逆於心絡也。咳嘔腹脹。且飧泄。其脈絶。逆於肝脾之絡也。夫胃者。水穀血気之海也。五臓之大絡。海之所以行云気於天下之道路也。水天之気。上下相通。一昼一夜。繞地環転一周。如逆而不行。則開闔已息。是以不過一周而死矣。夫人皮以応天。皮膚之気血。逆而不行。不過一周而死。工不察此天運之大道。如逆傷其気。遅則死於家中。速則死於堂上矣。任穀庵曰。以上論人之気血。参合天地之道。営運無息者也。少有留滞。或漸積而成癰膿。或一息不続。即為霄壌之判。黄帝曰。夫子之言針甚駿。以配天地。上数天文。下度地紀。内則五臓。外次六腑。経脈二十八
