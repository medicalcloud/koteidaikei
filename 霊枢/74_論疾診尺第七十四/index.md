# 論疾診尺第七十四

## 篇末の音釈（原文）

目窠（音科）窅（音杳）炬然（及許切亦作及然）齲（丘禹切歯蠧）掣（尺制切）痎瘧（上音皆痩瘞也）

【校異】「杳炬然**及許**切亦作」を，Wikisource（靈樞經・四庫全書本）は「杳炬然**其呂**切亦作」に作る。

【校異】「音皆痩**瘞**也」を，Wikisource（靈樞經・四庫全書本）は「音皆痩**病**也」に作る。
