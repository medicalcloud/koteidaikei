# 素問 六微旨大論篇第六十八 §60 (English translation)

## Translation of the text

The Emperor said: "Good. Cold and damp meet, dryness and heat face each other, wind and fire encounter each other. Is there a difference among them?"

## Notes

There is no note by Wang Bing.
- The base's 其有聞乎 is emended to 其有間乎. The *Leijing* and the Daizhige *Chongguang buzhu* text read 間, and the *Leijing* explains 間 as "difference: because there is a difference, there are pathogenic and proper [qi], and changes arise". This fits Qibo's reply (qi has prevalence and retaliation, virtue, transformation, function and change), so the graphically similar 聞 is taken as an error for 間. Zhang Zhicong's *Jizhu*, Wikisource (the plain text) and the Daizhige *Huangdi neijing suwen* read 聞.
