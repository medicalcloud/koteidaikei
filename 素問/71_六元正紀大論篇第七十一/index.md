# 六元正紀大論篇第七十一

## 篇首の張志聡集注（原文）

【集注・解題】此篇論六気主司天於上在泉於下五運六気運化於中間気紀歩為加臨之六気以主時五六相合以三十年為一紀再紀而為一周故名六元正紀大論

## 篇末の釈音（原文）

憒（音会）矇（音蒙）憹（奴董切）融（胡革切）痙（臣郢切）
