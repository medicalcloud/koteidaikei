# 素問 病能論篇第四十六 §12 (English translation)

## Translation of the text

Qibo said: "These have the same name but differ in kind. Where the qi of the abscess has become a growth, it should be opened and removed with the needle; where the qi is abundant and blood gathers, it should be drained with the stone. This is what is called treating the same illness differently."

## Translation of Wang Bing's commentary and the Song editors' notes

[On "These have the same name but differ in kind"] It says that although both are called neck abscesses, what lies inside the skin differs and is not of one kind. Hence below it says:

[On "Where the qi of the abscess has become a growth ... treating the same illness differently"] 息 means 瘜, dead flesh. 石 means the *bian* stone, which can break a large abscess and let out pus; nowadays the 䤵 needle is used instead.

## Notes

The principle of "treating the same illness differently": the same name of illness with different conditions calls for different treatments. A frequently quoted phrase.
- 瘜 in Wang Bing's note was supplied where it was lost in the sources (see the 【補】 note).
