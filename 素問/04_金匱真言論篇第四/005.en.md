# 素問 金匱真言論篇第四 §5 (English translation)

## Translation of the text

The Emperor said: "The five zang correspond to the four seasons; does each have things it gathers and receives?"

## Notes

Huangdi asks whether each of the five zang, in its correspondence with the four seasons, has its own set of corresponding things. The next unit sets out in detail the correspondences of the five directions, colours, flavours and so on.
- There is no note by Wang Bing.
