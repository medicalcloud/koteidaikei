# 解精微論篇第八十一

## 篇首の注（原文）

【篇名への注】【新校正】新校正云按全元起本在第八巻名方論解

## 篇首の張志聡集注（原文）

【集注・解題】精者天一所生之精微者天道之幽遠也此九九数終復帰於真元之論

（巻24の巻末。Wikisource の入力にはなく，Kanripo KR3e0001 による）毚（士銜切）湊（麄勾切）
