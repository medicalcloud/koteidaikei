# 素問 標本病伝論篇第六十五 §12 (English translation)

## Translation of the text

When illness arises with surplus, it is root then branch: first treat the root, then the branch. When illness arises with insufficiency, it is branch then root: first treat the branch, then the root.

## Translation of Wang Bing's commentary and the Song editors' notes

[On "When illness arises with surplus ... then the root"] "Root then branch" means there is an earlier illness and then a later one; since there is surplus, first treat the root and then the branch. "Branch then root" means that what arose first is slight and slow, and what arose later is severe and urgent; since there is insufficiency, first treat the branch and then the root.

## Notes

The order of treating branch and root is decided by surplus and insufficiency.
