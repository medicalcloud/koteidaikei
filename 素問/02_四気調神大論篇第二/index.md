# 四気調神大論篇第二

## 篇首の注（原文）

【篇名への注】【新校正】新校正云按全元起本在第九巻一

## 篇首の張志聡集注（原文）

【集注・解題】神蔵於五臓故宜四気調之脾不主時旺於四季月
